🔐 Python Tkinter Password Generator

A sleek, lightweight desktop application built with Python and Tkinter that generates strong, randomized passwords based on a user-specified length.

✨ Features
Customizable Length: Set any desired length for your generated passwords.
Secure Character Set: Combines uppercase and lowercase letters, digits, and special characters (!@#$%^&*()).
Modern Dark UI: Features a clean, dark-themed user interface styled with custom colors using Tkinter.
Zero Dependencies: Built entirely with standard Python libraries—no additional packages to install!

🛠️ Prerequisites
To run this application, you only need Python installed on your system:
Python 3.x
(Note: Tkinter comes pre-installed with most standard Python distributions on Windows and macOS. Linux users may need to install python3-tkinter via their package manager).

🚀 Getting Started
1. Clone or Download
Download or save the script file locally as Password Generator.py.
2. Run the Application
Open your terminal or command prompt, navigate to the directory where the file is saved, and run:
python "Password Generator.py"


📖 How to Use
Launch the application.
Enter your desired password length in the input field (defaults to 12).
Click the Generate Password button.
Your newly generated secure password will appear at the bottom of the window!

💻 Tech Stack
Python 3
Tkinter (GUI framework)
Random & String (Standard libraries for random selection and character sets)
